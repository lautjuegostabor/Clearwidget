# ClearWidget v0.5.4 — integration candidate

Base 46ea4de94be2103131b2649f5df776e9c4a0d754. The approved views, kind, bundle identifiers and Open-Meteo fallback remain intact. The version is 0.5.4/build 10. The native Rust source snapshot is pinned to BariStore 56165783f31d3e441ae9f76df42c3cc55e239777; all 53 included upstream file blob hashes were checked during transfer; CI rechecks them before compiling. Cargo dependencies and SDK remain external. No login or profile mutation was performed in CI.

The host-only App Intents, Spanish metadata, and Keychain bridge with extension acknowledgement are integrated. The bridge requires a matching Apple-authorized, signed keychain group in both targets. Standard BariStore does not add it; the narrow signer patch must be validated with the existing IDs and certificate, without signing unrelated apps or creating/revoking certificates. Unsigned metadata is not proof of installed Shortcuts discovery. Actual weather/activity acquisition shortcuts and locked-device operation remain to be verified.

ClearSign includes explicit local pairing and single-route authentication, plus effective BGTask ID lookup. LocalDevVPN, Apple developer services and the selected anisette provider remain dependencies. No password persisted by design; the code uses a non-public authentication protocol, and account/session security is not independently audited. No actual account tests. ClearRecovery source can decrypt an opt-in encrypted local backup and request profiles only. It cannot recover a revoked certificate or invalid Apple session. The guest target is selected based on the pinned upstream documented aarch64-musl build, not on a measurement from the user's iPhone. CI build/test success does not establish on-device recovery or successful renewal across expiry.

The recovery signer is compile-tested only, not distributed automatically: the original UI, update routes and behavior still require an independent security review. Do not enter real credentials or install until the relevant paths are validated. Do not merge into main or modify stable branches.
