# Audit: ClearWidget 0.5.9 build 15
Base: build 14, commit 34b5e262aac287185afd29e410213bbb526eca09.
Scope: only the three external Shortcuts actions, their local data receipt, and build reproducibility. No signer, background renewal, layouts, navigation or artwork changes.
- Routing: both targets contain the intents, host-only provider, explicit widget execution target, extension-only runtime guard. Apple's documented target API supports the design; real Shortcuts routing on the installed device remains unverified. Historical v0.5.6/7 attempted widget routing; metadata alone does not establish success.
- Remove the legacy Keychain consumer from timelines: no legacy cross-process reads during this trial. Legacy source remains in the tree for rollback, but has no active callers in the revised shortcuts or provider.
- Serialize new Apple weather writes with the existing weather service actor; do not rate-limit an explicitly submitted input. Verify persistent readback.
- Receipts: one latest per kind, exact input timestamp and activity values/source, only visible weather timeline data qualifies, generic refresh confirms diagnostic only. Tests cover stale cache, wrong values, fallback data, independent receipts, expiry and reset.
- Build: reuse the SHA-256 verified Assets.car and regenerate the exact 354px band geometry from the old generator formula. No external artwork fetch. Build 14 artifact is an expiring dependency; archive the original artwork/catalog for future reproducibility. Packaging checks verify original bundle IDs, versions and catalog hash.
- Evidence limitation: local tests do not run system AppIntents routing, do not render the home screen, and cannot validate signed runtime on the physical iPhone. Apple AppIntentsTesting is a potential further integration test but is not implemented in this release. Do not report success until device validation.
