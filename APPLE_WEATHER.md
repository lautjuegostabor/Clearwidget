# Apple Weather bridge (experimental on sideloaded iOS)
ClearWidget 0.5.2 supports a local App Intent called **Guardar clima de Apple**. No WeatherKit entitlement or private API. Apple Shortcuts must obtain the actual forecast and send it. No automatic Shortcut installation. The action is included in both the main app and widget extension for discovery; only widget-extension execution is allowed because they do not share a signed App Group. Confirm on-device that the action is discoverable and can write the extension's local cache with BariStore. Until then Open-Meteo is the working fallback after location permission.
 
## Shortcut
Name: Actualizar clima ClearWidget. Obtain current location, current weather, hourly forecast and daily forecast for the same location. Convert temperatures to Celsius. Use the next 5 or more full forecast hours in chronological order, one hour apart. Get tomorrow's maximum from the second daily result. Derive each isDay from local sunrise/sunset for its date. Use seconds since 1970 (not milliseconds) for time; use current time for current. Use Dictionary/List and convert to JSON text. Call Guardar clima de Apple with that text. Example shape (values illustrative; use actual live data):
```json
{"latitude":-31.4,"longitude":-64.2,"current":{"time":1795629600,"temperature":24.5,"condition":"Parcialmente nublado","isDay":true},"hourly":[{"time":1795633200,"temperature":25,"condition":"Nublado","isDay":true},{"time":1795636800,"temperature":24,"condition":"Nublado","isDay":true},{"time":1795640400,"temperature":23,"condition":"Nublado","isDay":true},{"time":1795644000,"temperature":22,"condition":"Nublado","isDay":false},{"time":1795647600,"temperature":21,"condition":"Nublado","isDay":false}],"tomorrowHigh":28,"timezone":"America/Argentina/Cordoba"}
```
Run once unlocked and grant permissions. Assign this shortcut to Abrir Clima (medium) or Acción principal (small) for manual refresh; optionally append Open App to the shortcut. Set personal time-of-day automations, Run Immediately, once per hour if desired (24 daily triggers if no recurring hourly option). iOS does not guarantee hourly execution, locked-device permissions, or instant timeline updates. Test locked operation. Navigation buttons remain cache-only; arbitrary Shortcut execution cannot be called from SelectPage. Unassigned widget actions stay inert.
 
Apple data preferred for 75 minutes, fallback requested at WidgetKit's approximately hourly opportunities. Minimum five minutes between accepted same-area Apple updates and fallback HTTP attempts. No networking per individual widget. Location sampled only when the system requests a timeline; app requests When In Use, widget must be allowed. If denied, only recent location from a successful Shortcut can supply a fallback; no fixed city is silently substituted. The bridge is not yet validated on a signed device.
