# ClearWidget v0.5.18 — experimental independent native glass
Base build 23 5cb0913f0c7b7608041d3eaf9cfde22f1ad58895. The user-provided Widgy 27.0.1 extension was inspected locally: its private descriptor pipeline uses the WidgetKit XPC exported object's getAllCurrentDescriptorsWithCompletion: and getCurrentDescriptorsWithCompletion: methods, and the preferred background style enum value 2 for blur, value 1 for clear. No proprietary binary or source is incorporated. The new implementation instead uses a Foundation keyed-archiver delegate to substitute independent copies of matching ClearWidget descriptors while preserving all other encoded fields. Runtime signature checks, exact widget kind, secure coding, original result fallback and exclusion of control descriptors. No changes to designs, timeline, weather, actions, signing or IDs. No screenshot, extra privileges, networking or periodic refresh. Private API can change across iOS versions; visual Liquid Glass refraction is not verified by static inspection or macOS tests. A successful build confirms the code is bundled, not that iOS renders glass. The existing original container backgrounds remain intact. No setting was added because a single widget kind is used for all four designs. Branch build and on-device verification with normal and transparent system appearances are separate from source audit.
